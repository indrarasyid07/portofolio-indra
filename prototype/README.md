# Prototype Portofolio

Prototype visual dan navigasi untuk meninjau pembagian halaman sebelum tech stack final dipilih.

## Menjalankan

Buka `index.html` di browser atau jalankan server statis lokal dari folder ini. Prototype tidak memakai backend, tidak menyimpan formulir, dan tidak menentukan framework produksi.

## Halaman

- Beranda: nama, slot foto, perkenalan, dua sorotan proyek.
- Profil
- Pengalaman
- Pendidikan & sertifikasi
- Proyek (detail dapat dibuka per item)
- Tech stack umum
- Kontak (formulir pratinjau)

Konten riwayat, proyek, foto, dan teknologi masih placeholder. Ganti setelah data asli tersedia.
