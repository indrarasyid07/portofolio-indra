# Roadmap

**Status:** Draft awal

## Tahapan usulan

1. Selesaikan brief, konten profil, arah visual, dan sketsa responsif.
2. Putuskan stack dan model data.
3. Bangun situs publik dan panel admin minimum.
4. Isi konten asli, lakukan pemeriksaan kualitas, lalu rilis.
5. Evaluasi fitur lanjutan seperti blog, testimoni, dan statistik.

Urutan dan cakupan dapat berubah setelah stack dan konten final dipilih.
