# Dokumentasi Portofolio Indra

Dokumentasi produk dan implementasi situs portofolio programmer. Dokumen ditulis dalam bahasa Indonesia. Struktur ini disesuaikan dengan kebutuhan proyek agar spesifikasi produk, rancangan, dan implementasi mudah ditemukan tanpa memecahnya ke terlalu banyak kategori.

## Peta dokumentasi

| Folder | Cakupan |
|---|---|
| `00-overview` | Ringkasan proyek, status, dan tautan penting. |
| `01-product` | Tujuan, audiens, kebutuhan, dan ruang lingkup. |
| `02-design-and-content` | Arah visual, struktur halaman, konten, dan model isian profil/proyek. |
| `03-architecture` | Pilihan teknologi, komponen sistem, API, dan data teknis. |
| `04-admin-and-security` | Alur panel admin, autentikasi, hak akses, dan keamanan konten. |
| `05-quality-and-operations` | Pengujian, aksesibilitas, deployment, backup, dan pemeliharaan. |
| `06-roadmap` | Tahapan pengerjaan dan rencana rilis. |
| `07-decisions` | Keputusan penting beserta konteks dan dampaknya. |
| `99-archive` | Dokumen lama yang tetap perlu disimpan. |

## Konvensi

- Gunakan nama file huruf kecil dan tanda hubung, misalnya `visual-direction.md`.
- Tandai usulan yang belum disetujui sebagai **Usulan** dan pilihan yang belum ditentukan sebagai **Perlu diputuskan**.
- Perbarui dokumen terkait saat kebutuhan atau implementasi berubah.
- Simpan keputusan yang memengaruhi beberapa bagian proyek di `07-decisions`.
