# Brief Portofolio Programmer

**Status:** Draft awal  
**Bahasa situs:** Indonesia  
**Prototipe Figma:** [Portofolio Programmer — Draft](https://www.figma.com/design/laPbFUjnYTdEFX5ks9FsEI)

## Tujuan

Membuat situs portofolio programmer yang memperkenalkan pemiliknya, menunjukkan pengalaman dan hasil kerja, serta menyediakan cara mudah untuk menghubunginya. Konten utama harus dapat diperbarui melalui panel admin tanpa mengubah HTML secara manual.

## Audiens

- Recruiter dan calon pemberi kerja
- Calon klien atau kolaborator
- Pengunjung yang ingin melihat proyek dan kemampuan teknis

## Kebutuhan konten

1. **Profil:** nama dan foto terlihat jelas sejak bagian pembuka, disertai peran dan ringkasan singkat.
2. **Pengalaman kerja:** posisi, organisasi, periode, deskripsi kontribusi, dan pencapaian bila tersedia.
3. **Pendidikan:** institusi, program, periode, dan keterangan relevan.
4. **Kursus dan sertifikasi:** nama, penerbit, tanggal, serta tautan bukti jika ada.
5. **Proyek:** ringkasan masalah dan solusi, peran pemilik, hasil, tautan demo/repo, serta tools dan tech stack khusus proyek.
6. **Kemampuan umum:** tools dan tech stack yang digunakan secara umum.
7. **Kontak:** email atau formulir kontak dan tautan profesional yang dipilih.
8. **CV:** opsi melihat atau mengunduh CV.

## Panel admin

- Login admin untuk membatasi akses pengelolaan.
- Tambah, edit, hapus, dan atur urutan konten profil, pengalaman, pendidikan, kursus/sertifikasi, proyek, kemampuan, dan tautan.
- Unggah foto profil dan gambar proyek.
- Validasi input sebelum disimpan.
- **Perlu diputuskan:** perubahan langsung terbit atau dapat disimpan sebagai draft terlebih dahulu.

## Arah visual

**Usulan awal:** terminal modern dengan nuansa Linux/shell. Gunakan panel bergaya terminal, prompt dan syntax highlighting sebagai detail visual, sambil menjaga nama dan foto sebagai fokus pembuka serta keterbacaan isi.

Palet eksplorasi:

| Peran | Warna |
|---|---|
| Latar utama | `#101410` |
| Panel/kartu | `#171D18` |
| Garis/pembatas | `#2A342C` |
| Teks utama | `#E8EFE7` |
| Teks sekunder | `#A5B0A4` |
| Aksen utama | `#A6E22E` |

Arah ini masih perlu disetujui sebelum dijadikan desain final. Pertimbangkan sans-serif untuk isi dan monospace untuk label teknis atau elemen terminal.

## Kebutuhan kualitas awal

- Tampilan beradaptasi untuk ponsel dan desktop.
- Kontras, navigasi keyboard, dan teks alternatif untuk foto diperhatikan.
- Judul dan deskripsi halaman dapat diatur untuk tampilan mesin pencari dan pratinjau tautan.
- Data kontak dan tautan eksternal dapat diperbarui melalui panel admin.

## Belum diputuskan

- Nama dan foto profil final serta isi CV.
- Pilihan framework, backend, database, dan hosting.
- Apakah situs hanya berbahasa Indonesia atau menyediakan bahasa tambahan.
- Apakah proyek menampilkan demo, repo, atau keduanya.
- Kebutuhan blog/tulisan, testimoni, dan statistik.
- Alur publikasi konten dari panel admin.
